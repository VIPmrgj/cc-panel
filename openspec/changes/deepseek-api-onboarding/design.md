## Context

参见 `proposal.md`。当前 `OnboardingDialog` 只负责展示步骤，模型配置保存和原生凭据输入由 `App` 与 `AddModelDialog` 处理；模型配置已经通过系统保护存储 API Key，但还没有用户主动触发的连接测试命令。现有提供商目录已经包含 DeepSeek 的 Anthropic 兼容地址和默认模型。

## Goals / Non-Goals

**Goals:**

- 在现有新手引导中增加一个独立、可返回、可跳过的 DeepSeek 向导。
- 复用现有模型保存和系统凭据保护，避免新增明文密钥通道。
- 用后端安全地执行最小连接测试，并只向前端返回经过分类的结果。
- 保留其他 API 的通用高级配置，不改变现有模型选择和会话启动契约。
- 让失败状态、加载状态、焦点和深色模式在视觉上清楚可见。

**Non-Goals:**

- 不替用户注册 DeepSeek、读取浏览器内容或代替用户输入账号密码。
- 不制作其他服务商的逐一申请教程。
- 不在保存配置时自动消耗 API，不实现连续监控或余额查询。
- 不把 Ollama Prompt 优化改造成 Claude Code 主模型。

## Decisions

### 1. 以独立向导承载 DeepSeek 示例

新增 `DeepSeekApiWizard`，由引导步骤打开；不把申请说明塞进现有 `AddModelDialog`。这样基础路径只处理一个主要动作，已有高级用户仍可从模型栏直接使用原表单。

备选方案是把所有说明放在现有表单中，但这会让新手同时看到 API 地址、模型 ID和备注字段，违背渐进披露，因此不采用。

### 2. 向导复用现有保存命令

向导使用当前 `prompt_and_save_model_profile` 保存 API Key，让密钥继续只经过原生凭据窗口和后端保护存储。向导只构造不含密钥的 `ModelProfileInput`，不新增 renderer secret 字段。

### 3. 连接测试按已保存 profile ID执行

新增 `test_model_profile_connection` 命令。后端通过 profile ID从保护存储解析密钥，构造 Anthropic `messages` 最小请求（`max_tokens` 为 1），使用短连接/请求超时、禁止重定向和有限响应读取。前端只接收 `ok`、分类代码、用户提示和模型/提供商展示信息。

备选方案是让前端直接传 API Key 或让 Claude CLI承担测试，但前者破坏密钥边界，后者会启动完整会话并混淆测试与真实对话，因此不采用。

### 4. 连接测试分成配置保存和真实请求两步

保存成功不自动请求模型。向导先显示“配置已保存，尚未测试”；用户点击测试后弹出一次费用提醒并执行请求。测试结果通过 TanStack Query mutation 管理，期间禁用重复提交但保留取消/关闭向导能力。

### 5. 失败分类不透传服务商响应体

后端按 HTTP 状态和网络错误映射为认证、限流/余额、配置、网络、服务端和未知失败。服务商原始响应体不返回前端，避免响应中夹带敏感信息或大段错误内容；日志不得写入 URL 查询、请求头或响应正文。

### 6. 预设来源保持单一

向导从现有 `providerCatalog` 的 DeepSeek 预设读取地址和模型展示值；不在向导内重复硬编码。若预设变化，基础引导和高级表单保持一致。

## Risks / Trade-offs

- [真实测试可能产生费用] → 测试必须由用户主动触发，并在请求前展示费用提醒；请求使用最小输出。
- [不同兼容服务对 Anthropic 请求支持不完全一致] → 只把成功/失败作为连接能力检查，不承诺完整模型能力；失败提供高级配置入口。
- [服务商错误信息可能包含敏感数据] → 后端只返回分类结果和固定中文提示，不回显响应正文。
- [用户关闭向导后配置状态可能变化] → 每次打开向导重新读取模型 profile，保存和测试成功后刷新 Query 数据。
- [桌面窗口尺寸较小时说明过长] → 向导主体滚动、底部操作固定、正文保持短句，并为按钮提供明确的 aria-label。

## Migration Plan

1. 增加 DTO、API 命令、后端测试命令和前端向导，不改变现有模型配置文件格式。
2. 在引导中将“添加模型配置”改为打开 DeepSeek 向导；模型栏继续打开原高级表单。
3. 运行前端类型、Lint、格式、测试和 Rust 格式、Clippy、测试。
4. 构建安装包并手动验证：取消凭据、保存未测试、成功测试、401、超时、跳过引导和进入高级配置。
5. 若需要回滚，移除新向导入口并保留原有模型配置命令；数据格式无需迁移。
