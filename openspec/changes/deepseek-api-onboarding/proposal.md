## Why

当前新手引导能安装 Claude Code，却在需要模型时直接把用户带到“提供商、API 地址、模型 ID、密钥”表单。用户不知道 API Key 去哪里申请，也无法判断配置是否真的可用，导致“已保存但未连接”或反复返回配置页面。

本次只为 DeepSeek 制作一条完整、可跟随的示例路径，让用户先学会一次模型接入流程；已有其他 API 的用户仍保留通用高级配置，不把 CC Panel 限制为单一供应商。

## What Changes

- 在新手引导的默认模型步骤中加入 DeepSeek API 接入向导，以单页单目标的方式展示申请、复制密钥、保存和验证流程。
- 提供“已有其他 API Key”和“稍后配置/本地体验”出口，避免所有用户都被强制带入 DeepSeek 流程。
- 基础模式只展示 DeepSeek、API Key 和连接验证；API 地址、模型 ID 等保留在高级配置中并由预设自动填充。
- API Key 继续通过原生系统凭据输入和本地保护保存，不经 React 状态或普通 IPC 明文传递。
- 增加用户主动触发的模型连接测试，并区分配置错误、认证失败、模型无权限、余额不足、网络失败等结果。
- 补充引导过程中的加载反馈、内联错误、跳过/返回、键盘焦点和深色模式样式。

## Capabilities

### New Capabilities

- `api-onboarding`: 面向新手的 DeepSeek API 获取、保存与连接验证引导。

### Modified Capabilities

无。

## Impact

- 前端：`OnboardingDialog`、模型配置组件、API DTO/命令封装和相关样式测试。
- 后端：模型配置命令增加安全的连接验证入口，使用已有 `reqwest` 客户端能力并继续从系统保护存储解析密钥。
- 提供商目录：复用现有 DeepSeek Anthropic 兼容地址与模型预设，避免重复写死配置。
- 不新增第三方依赖，不改变其他提供商的通用配置能力，不自动发起可能产生费用的模型请求。
