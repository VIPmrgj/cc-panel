# Debug and Refactor Core

## Why

CC Panel 的核心会话转换与前端对话状态长期叠加在少量超大模块中，多个会话切换、权限和恢复分支重复构造临时状态。它们当前能工作，但修改一个分支时很容易遗漏另一个分支，增加卡死、状态不同步或回归的风险。

现有覆盖率采集范围也包含构建产物，报告冗余且无法准确衡量应用源码；新增的开发规范模板则会触发与产品代码无关的格式检查失败。

## What Changes

- 把 Claude 协议事件到前端事件封装的纯转换逻辑从会话命令模块拆到内部专用模块，保持 Tauri 命令和 IPC 数据结构不变。
- 收敛前端聊天状态中重复的“结束当前回合”状态复位，避免权限、工具进度和恢复字段在不同会话分支中漂移。
- 修正覆盖率范围，仅统计 `src/` 应用源码；忽略自动生成的开发规范模板，恢复可重复的质量门禁。
- 补充或调整针对转换和状态复位的测试，并运行前后端完整验证。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。本变更不设计新的产品行为或 IPC 契约，因此跳过规范增量。

## Impact

- `src-tauri/src/commands/sessions.rs` 及新增内部事件转换模块。
- `src/state/chatReducer.ts` 及其测试。
- `vite.config.ts`、`.prettierignore` 与开发质量报告。
- 不新增运行时依赖，不改变模型、权限、队列、对话历史或安装流程的用户可见功能。
