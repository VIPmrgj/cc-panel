## Context

会话命令模块同时承担 Tauri 命令、会话生命周期、协议转换、历史内容转换和错误映射，体积过大。前端 reducer 在会话离开、加载、启动时分别复制相近的临时状态清理字段。两处都容易在后续功能增加时产生不一致。

## Goals / Non-Goals

**Goals:**

- 保持现有 IPC、会话状态机和界面行为不变。
- 为协议事件转换建立单一、可单测的内部边界。
- 让聊天回合清理字段集中定义，并保留每个动作原本的差异。
- 让质量检查和覆盖率报告只关注应用源码。

**Non-Goals:**

- 不重新设计会话调度、权限规则、输入队列或 App 页面布局。
- 不删除用户数据、构建缓存或已有安装包。
- 不引入新的第三方依赖。

## Decisions

### 1. 事件转换拆为 `commands::session_events`

该模块只包含协议/会话事件到 DTO 的转换、历史消息展示转换、会话错误映射和相关辅助函数。`commands::sessions` 保留 Tauri 命令、状态访问和事件转发。通过 `pub(super)` 暴露少量入口，避免扩大 crate 公共 API。

### 2. 仅抽取 reducer 的共享“回合清理”字段

使用小型纯辅助函数统一 `turnStatus`、活动助手、活动工具、恢复状态、权限消息和最后事件时间的复位。会话离开、加载与启动仍在各自分支设置生命周期、运行标识、序列号等特有字段，避免过度抽象掩盖状态差异。

### 3. 收紧质量工具输入

Vitest 覆盖率限制到 `src/**/*.{ts,tsx}`，不会再把 Rust 目标目录和捆绑资源写入报告。Prettier 忽略 OpenSpec 自动生成的 Claude 命令模板；变更说明本身仍纳入格式检查。

## Risks / Trade-offs

- Rust 模块拆分可能遗漏私有类型或时间函数依赖；用编译、Clippy 和完整 Rust 测试验证。
- reducer 辅助函数若把不同分支的字段错误地统一，可能影响中断后继续对话；保留现有动作的差异，并由现有 reducer 测试覆盖。
- 覆盖率收紧后数字会变化，但变为真实的应用源码覆盖率而非噪音。

## Migration Plan

这是纯内部重构，可随单个提交回滚。完成后运行前端格式、类型、Lint、测试/覆盖率以及 Rust 格式、Clippy、测试；随后构建 Windows 安装包进行发布验证。
