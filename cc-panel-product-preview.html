安装前需要知道

CC Panel 是 Claude Code 的图形控制面板。真实 Agent 对话需要本机可用的 Claude Code 和一个已配置的模型；没有 API Key 时可以先使用演示模式。

安装包从哪里来

安装包由 GitHub Actions 在 Windows 环境构建并发布。源代码、构建记录和版本标签均可在 GitHub 仓库查看。

KNOWN LIMITATIONS

已知问题，先说清楚。

这些内容不会阻止核心试用，但正式发布前仍值得继续处理。

P1 / 验证

真实 Claude Code 认证环境的完整 GUI 往返仍需要更多不同机器和网络条件下的人工验收。

P1 / 发布

安装包目前还没有正式代码签名，部分 Windows 环境可能显示 SmartScreen 提示。

P2 / 性能

前端生产包仍有较大的主 JS chunk；PDF 解析目前在主进程中，大型文件可能影响响应速度。

P2 / 测试

自动化测试覆盖核心状态和组件，但权限、进程退出、模型网络异常仍需要更深的集成测试。
